# Terms

This document contains definitions of terms used throughout the project.

| Term | Definition |
|------|------------|
| Cylinder Module | A removable cylindrical component that houses a cluster of bee tubes. |
| Carrier Body | The main structure that holds multiple cylinder modules in a grid and features an integrated solid back. |
| Bee Tube | A 3/8 inch diameter tunnel where mason bees lay their eggs. |
| Wall Mounting Bracket | A separate bracket attached to a wall or post that the carrier body slides onto. |
| Locking Nub | A spherical protrusion inside the carrier body that mates with the cylinder module's groove. |
| Locking Groove | A channel on the cylinder module that guides and secures the locking nub. |
| Parchment Paper Template | A tool used to trace and cut parchment paper liners for the bee tubes. |
| Paper Insertion Tool | A tool to help roll and insert the parchment paper liners into the bee tubes. |
| Candle Spacing | The minimum distance between the centers of adjacent regular candle holders on a face: at least 1.0 inch (25.4 mm). They may be spaced further apart where a larger spacing yields a more symmetrical arrangement. (Requirements Constraint #3.) |
| Arc-Top Separation | The minimum lateral separation between the innermost candle tops of the two symmetric arcs on a face: 0.5 inches (12.7 mm). Keeps the shamash visible when the face is viewed from its base edge through the candle forest. (Requirements Constraint #4.) |
| Same Level | The halachic requirement that all eight Chanukah candles sit at the same height above the surface on which the menorah stands. On the die, when it rests on a face the top face is horizontal, so every candle on it is at the same level automatically, regardless of the 2-D pattern. |
| Shamash | The servant candle used to light the others; it is clearly not one of the eight and must be raised, lowered, off to the side, or in the center so it is unmistakably separate. On the die it sits at the triangle's point of each face. |
| Left-to-Right Ordering | The ritual ordering of Chanukah candles: set up starting from the right side, add each night's new candle on the left (accumulation proceeds right to left), and light from left to right as the lighter faces the menorah. |
| Pirsumei Nisa | The purpose of lighting Chanukah candles: publicizing the miracle. The reason underlying the arrangement rules. |
| Face Layout | The pattern of candle-hole centers on a face plate, produced by a pluggable layout strategy (`FaceLayout` in `src/manora/face_plate_layouts.py`). Existing: `circular`. Candidate patterns: row, arc, circle, staggered/packed. |
| Horizontal Curvature | The halachic allowance that the menorah itself may be curved in plan view (viewed from above) as long as the candles remain at the same level. On the die's flat top face any 2-D pattern is such a curve. |
